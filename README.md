# Página de Fans de River Plate

Esta es una página web simple creada para los fans del Club Atlético River Plate.

## Cómo ver la página en local

Para ver la página en tu computadora, sigue estos pasos:

1. Asegúrate de tener Python instalado.
2. Abre una terminal o línea de comandos.
3. Navega al directorio donde se encuentran los archivos.
4. Ejecuta el siguiente comando:

```bash
python serve.py
```

5. Abre tu navegador web y ve a `http://localhost:8000`.
